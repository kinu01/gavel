# What this project is for

This file tells Gavel what fits the project. Keep it short and honest. Gavel quotes it when it calls an issue in scope or out of scope.

- What the project does, in one or two sentences.
- Who it is for.
- What it will never do, for example "no plugin system" or "no GUI".
- What matters most when choices clash, for example "correct output before new features".
